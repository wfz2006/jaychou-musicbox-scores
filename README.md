# 周杰伦三十音八音盒谱 · MusicXML / MIDI

十二首周杰伦钢琴谱改编而成的**指定三十音八音盒**可演奏分谱（旋律 + 伴奏双声部），每首提供两种格式：

| 文件 | 说明 |
| --- | --- |
| `*.musicxml` | MusicXML 4.0 Partwise（实音记谱、无隐藏 `<transpose>`），推荐主用 |
| `*.mid` | Standard MIDI File（Format 1），与 `.musicxml` 严格对齐，供 DAW / 播放器试听 |

## 三十音机械约束与校验

全部 12 首作品已通过机械约束与盘面一致性校验（越界音 `0`、速度违规 `0`、同音重拨违规 `0`、最小同音间隔 `1q`、未展开/未解决项 `0`，`.musicxml` 与 `.mid` 音高/起音/时值/速度完全一致）：

- **可用音高集合（30 个离散音，实音记谱）**：
  - `F3, G3`
  - `C4, D4, E4, F4, G4, A4, Bb4, B4`
  - `C5, Db5, D5, Eb5, E5, F5, Gb5, G5, Ab5, A5, Bb5, B5`
  - `C6, Db6, D6, Eb6, E6, F6, G6, A6`
  - 不包含 `A3, B3, Db4, Eb4, Gb4, Ab4, Gb6, Ab6, Bb6`
- **速度范围**：四分音符 `100–220 BPM`（含边界）
- **同音重拨间距**：全曲合并所有声部后，相同音高相邻起音间距 `≥ 1` 个四分音符

## 使用方法

- **打孔 / 记谱软件**：MuseScore、Dorico、Sibelius、MusicBoxManiacs 等可直接导入 `.musicxml`。
- **试听 / 音频导出**：将 `.mid` 拖入 DAW 或播放器试听。
